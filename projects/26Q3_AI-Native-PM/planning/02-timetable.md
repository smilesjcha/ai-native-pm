## 운영 원칙

1. **구간 종료 시각을 우선 지킨다.** 지연 시 개별 실습 결과 공유를 줄이고 강사 모범 결과로 전환한다.
2. 실습 대기 시간은 각 모듈 배정 시간 안에 포함한다. 실습은 항상 "입력 → 결과 확인 → 한 번 수정" 3단계.
3. 쉬는시간 20분 중 앞 5분은 질문 수집·환경 트러블 대응에 쓴다(강사는 자리에 남는다).
4. 점심 직전 20분 쉬는시간(11:10–11:30)은 오전 실습 미완료자의 **캐치업 시간**으로 안내한다.
