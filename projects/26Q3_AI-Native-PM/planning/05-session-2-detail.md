## 결론부터

- Session 2는 **"오전에 배운 요청 6요소로, 오후에는 문서를 만든다"** 세션이다. 하나의 가상 사례(머니핏)를 리서치 브리프 → 벤치마킹 표 → 제품 요구사항 정의서(Product Requirements Document, PRD) 초안 → 3관점 AI 리뷰 → 임원용 2-Pager까지 끊김 없이 이어간다.
- 수강생 산출물 **②**: PRD 초안 + 3관점 리뷰 결과 + 2-Pager 요약(+ 그대로 재사용할 프롬프트 5개: M5 벤치마킹·리서치 브리프, M7 PRD 초안·3관점 리뷰·2-Pager). 완성도가 아니라 **"요청 구조를 고쳐 다시 받는 경험"** 이 학습 목표다.
- 100분 배분: M4 재시동·머니핏 10분(3장) → M5 AI 리서치 25분(7장, 강의 10 = 장표 4–7 9분 + 실습 브리핑 1분 · 시연 7분 · 미니 실습 8분) → M6 기획서 구조화 20분(6장, 두 토막으로 끊어 15분 연속 강의 없음) → M7 실습 ③ 35분(8장, 4스텝: 입력 5·초안 10·리뷰 10·요약 10) → M8 공유·정리 10분(2장). 본편 총 26장 + 부록 3장(프롬프트 전문, 발표 시 건너뜀).
- 세션의 세 가지 습관: ① 출처 없는 문장은 삭제한다(M5) ② 사람이 뼈대(5개 입력·섹션·지표)를 먼저 정한다(M6) ③ 초안 대화와 리뷰 대화를 분리하고 사람이 결정한다(M7).
- 원 기획안 세부내용 매핑: "AI를 활용한 시장 분석 보고서 작성"·"경쟁사 분석과 벤치마킹 자동화" → M5 / "기획서·제안서 초안 생성과 구조화" → M6 / "실습: AI로 핀테크 서비스 기획서 작성하기" → M7.
