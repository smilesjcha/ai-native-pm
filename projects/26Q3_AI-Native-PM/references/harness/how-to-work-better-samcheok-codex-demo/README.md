# Codex 강사 확장 시연

이 폴더는 15분 확장 구간 중 5~7분에 보여 줄 수 있는 **강사용 선택 시연**입니다. 수강생 핵심 실습에는 Codex 설치, 유료 결제, 계정 연결, 코드 실행이 필요하지 않습니다.

## 시연 목표

새 Codex 대화에서 자료 폴더와 `AGENTS.md`, 완료 기준을 함께 제공하고, 교육용 메모를 보고서·기획서·검수 파일로 생성한 뒤 파일을 검토하는 흐름을 보여 줍니다.

## 재현 순서

1. Codex에서 새 대화를 열고 모델 `gpt-5.6-terra`, 추론 수준 `high`를 선택합니다.
2. 이 `05-codex-demo` 폴더와 상위 `01-report`, `02-plan`, `03-review` 폴더를 작업 범위로 제공합니다.
3. `demo-prompt.md`의 프롬프트를 붙여넣습니다.
4. 생성된 Markdown, 읽기용 PDF, 입력 CSV, XLSX를 모두 열어보고 사실·가정·확인 필요 표지와 숫자 일치를 확인합니다. 보고서·기획서 PDF는 실제 1페이지인지 확인합니다.

이 시연은 파일 기반 업무 확장의 예입니다. 무료 ChatGPT 핵심 실습을 대체하거나, 모델이 실제 무료 ChatGPT 실습을 수행했다고 주장하지 않습니다.

## 시연 지연 시

4분 안에 파일이 생성되지 않으면 `expected-outputs/`의 사전 제작 결과를 연다. “지금부터는 사전 제작한 교육용 모범 결과를 검토합니다”라고 말한 뒤 숫자·단위·확인 필요·마지막 결정 요청을 확인한다. 이 폴더는 라이브 실행 로그가 아니다.
