# 시연 완료 기준

- `demo-output`에 보고서, 기획서, 검수 결과 Markdown이 있다.
- 각 결과는 교육용 가상 사례임을 표시한다.
- 보고서는 2.4시간에서 4.1시간이 1.7시간 증가한 악화임을 정확히 쓴다.
- 기획서는 4개 시스템, 1인당 약 30분, 반복 누락 문의를 포함한다.
- 목표 수치와 통합 가능성·비용은 사실처럼 단정하지 않는다.
- 검수 결과는 근거, 누락, 중복, 실행 주체, 결정 요청을 확인한다.
- 보고서·기획서·검수 결과의 읽기용 PDF와 입력 CSV/XLSX를 만들고 파일을 연다.
- 보고서·기획서 PDF가 실제 1페이지인지 확인한다.
- 작업 범위 밖 파일을 바꾸거나 외부로 자료를 전송하지 않는다.
