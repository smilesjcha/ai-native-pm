# Codex 시연 작업 지침

## 범위

- 이 폴더와 지정된 교육용 실습 폴더 안의 파일만 읽고 작성한다.
- 실제 개인정보, 실제 기업 정보, 로그인 정보, 외부 전송은 금지한다.
- 교육용 가상 사례임을 문서마다 표시한다.

## 작성 규칙

- 한국어 본문과 ASCII 파일명을 사용한다.
- 숫자는 제공된 메모에 있는 값만 사실로 쓴다.
- 목표 수치는 `[가정]`, 확인 전 내용은 `[확인 필요]`로 표시한다.
- 보고서·기획서·검수 결과 Markdown 원본과 읽기용 PDF를 함께 만든다.
- 입력 데이터를 담은 CSV와 동일 내용을 담은 XLSX를 함께 만든다.
- 보고서·기획서 1페이지 결과 예시는 PDF가 실제 1페이지인지 확인한다.

## 완료 기준

`completion-criteria.md`의 항목을 모두 점검하고, 결과 파일 경로와 검수 결과를 마지막 메시지에 요약한다.
