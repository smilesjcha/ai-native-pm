# 공통 엔지니어링 가이드라인 (Claude + Codex)

이 문서는 Claude Code(`CLAUDE.md`)와 Codex(`AGENTS.md`)가 공유하는 단일 기준(Single Source of Truth)입니다.
하네스별 지침이 이 문서와 충돌하면 이 문서가 우선합니다.

## 1. 레포 목적

- "AX 시대의 일하는 방식" 관련 강의·워크숍 자료를 설계, 제작, 배포한다.
- 모든 산출물은 재현 가능해야 한다: 문서는 Markdown, PPT는 코드 빌드, 배포는 ZIP 패키징.

## 2. 디렉터리 규약

| 경로 | 용도 | 규칙 |
| --- | --- | --- |
| `lectures/<YYYYMMDD-slug>/` | 강의별 작업 공간 | 강의 간 파일 참조 금지(복사해서 사용) |
| `.../docs/` | 설계·커리큘럼·설문 | 번호 접두사(`01-`)로 읽는 순서 표현 |
| `.../design/` | 디자인 시스템·슬라이드 플랜 | PPT 코드보다 먼저 갱신 |
| `.../build_pptx/` | PPT 빌드 코드 | `theme.py`(토큰) / `layouts.py`(레이아웃) / `slides_data.py`(내용) / `build.py`(진입점) 분리 유지 |
| `.../materials/` | 수강생 배포 자료 원본 | 폴더 구조가 곧 ZIP 구조 |
| `.../dist/`, `.../output/` | 산출물 | 커밋 포함 (현장 즉시 사용 목적) |

## 3. 콘텐츠 규칙

- 언어: 문서·슬라이드·실습 자료는 한국어. 제품명은 원문 유지(`Claude`, `MCP`, `Skills`, `Notion`).
- 보안: 실제 개인정보·고객정보·기업 내부정보 금지. 샘플 데이터는 가상의 회사("한빛문구", "두리상사" 등)로 작성.
- 실습 난이도: 참여자 실습은 Claude 무료 계정 + 복사/붙여넣기 수준. 코딩·설치·계정 연동 금지.
- 유료/고급 기능(Claude for Excel·PPT·Word, MCP, Skills, Cowork)은 "강사 시연" 콘텐츠로만 다룬다.

## 4. PPT 품질 게이트 (머지/완료 전 필수)

1. `build.py` 실행이 에러 없이 끝난다.
2. 전 슬라이드를 이미지 렌더 후 확인:
   - 텍스트 오버플로우/잘림 없음 (텍스트 개행 수 대비 박스 높이 여유 확보)
   - 도형-도형, 도형-텍스트 겹침 없음
   - 동일 행 카드의 y좌표·높이 일치, 좌우 마진 대칭, 간격 리듬 일관
   - 안전 여백(상하 0.5in, 좌우 0.6in) 침범 없음
3. 색상·폰트는 디자인 시스템 토큰만 사용.

## 5. Git 규약

- 기본 브랜치 `main`에 직접 커밋 가능(1인 레포).
- **push 전 계정 확인**: 이 레포의 원격은 개인 계정(`smilesjcha`) 소유다. 이 머신의 gh 기본 계정은
  `sungjaecha-musinsa`이므로 push 시 `gh auth switch --user smilesjcha` 후 push하고,
  끝나면 `gh auth switch --user sungjaecha-musinsa`로 되돌린다.
- 커밋 메시지: 한국어 요약 한 줄 + 필요시 본문. 산출물 재생성 커밋은 `build:` 접두사.
- 대용량 원본(동영상 등)은 커밋하지 않는다. PPTX/PDF/ZIP 산출물은 허용.
