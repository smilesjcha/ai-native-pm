# 교육 전 체크리스트

교육 시작 전(가능하면 하루 전) 아래 항목을 확인해 주세요.

## 장비·환경

- [ ] 노트북 또는 데스크톱 PC (모바일만으로는 실습이 어렵습니다)
- [ ] Chrome 또는 Edge 브라우저 최신 버전
- [ ] 안정적인 인터넷 (Zoom + 웹 브라우저 동시 사용)
- [ ] Zoom 접속 테스트 (스피커·마이크)

## Claude 계정

- [ ] https://claude.ai 접속
- [ ] 무료 계정 가입 — **Google 계정으로 가입**하거나, 이메일 링크 방식으로 로그인
- [ ] 로그인 후 대화창에 "안녕하세요"를 보내 응답 확인

> 유료 결제는 필요 없습니다. 교육의 모든 직접 실습은 무료 계정 기준입니다.

## 실습 자료

- [ ] 배포받은 ZIP 파일 다운로드
- [ ] 압축 해제 후 `00_guide/workshop_guide.pdf` 열어보기 (Markdown 사용자는 `.md` 원본도 이용 가능)
- [ ] `outputs` 폴더 위치 확인 (실습 결과 저장용)

## 선택 (있으면 더 좋아요)

- [ ] Notion 계정 (실습 결과 정리용, Google 로그인 가능)
- [ ] 평소 반복적으로 하는 업무 1가지 떠올려 오기 → 마지막 세션 "나의 AI 업무 적용 시나리오"에서 사용합니다
