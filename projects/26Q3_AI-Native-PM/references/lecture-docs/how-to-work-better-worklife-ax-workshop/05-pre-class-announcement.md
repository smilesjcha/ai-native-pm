# 05. 수강생 사전 안내

## 필수 준비

| 구분 | 준비사항 | 이유 |
| --- | --- | --- |
| 필수 | 노트북 또는 데스크톱 PC | 모바일만으로는 실습이 어려움 |
| 필수 | Chrome 또는 Edge 브라우저 | Zoom과 Claude 동시 사용 |
| 필수 | Claude 무료 계정 생성 (claude.ai) | 직접 실습 도구 (Google 계정/이메일 링크 로그인 지원) |
| 필수 | 실습 ZIP 파일 다운로드·압축 해제 | GitHub 미숙련자 배려 |
| 필수 | 안정적인 인터넷 환경 | 온라인 실습 진행 |
| 필수 | 실제 회사자료 업로드 금지 인지 | 보안 리스크 방지 |

## 선택 준비

| 서비스 | 용도 | 비고 |
| --- | --- | --- |
| Notion | 실습 결과 정리, 개인 적용 시나리오 작성 | Google 로그인 가능 |
| ChatGPT | 다른 AI 도구 비교 | Google 로그인 가능 |
| Gemini / Google AI Studio | Google 기반 AI 비교 | Google 계정 |
| Perplexity | 자료조사형 AI 비교 | 출처 확인용 |
| Microsoft 365 | 유료 기능 시연 이해 | 필수 아님 |
| GitHub | 자료 재다운로드 | ZIP으로 대체 가능 |

## 사전 안내문 (메일 발송용)

```
본 교육은 AI 전환(AX) 시대의 업무환경 변화를 이해하고, 생성형 AI를 활용해
업무 생산성과 커리어 경쟁력을 높이는 방법을 실습하는 과정입니다.

실습은 무료 Claude 계정을 기준으로 진행되며, 유료 계정이 없어도 참여 가능합니다.
일부 유료 기능 또는 고급 연동 기능은 강사 시연으로 소개될 예정입니다.

원활한 실습을 위해 교육 전 아래 사항을 준비해 주세요.

1. 노트북 또는 데스크톱 PC
2. Chrome 또는 Edge 브라우저
3. Claude 무료 계정 생성 (https://claude.ai — Google 계정으로 가입 가능)
4. 실습 ZIP 파일 다운로드 및 압축 해제
5. 안정적인 인터넷 환경

실습 과정에서는 실제 개인정보, 고객정보, 기업 내부자료, 보안자료를 입력하지 않습니다.
모든 실습은 교육용 샘플 파일을 활용해 진행됩니다.
```
