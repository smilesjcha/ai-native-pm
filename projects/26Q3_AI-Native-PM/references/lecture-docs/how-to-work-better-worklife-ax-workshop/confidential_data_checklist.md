# 입력 전 30초 체크리스트

AI에 무언가를 붙여넣기 전, 아래 4가지만 확인하세요.

- [ ] **사람**: 실명, 연락처, 식별 가능한 개인정보가 들어 있는가? → 가명/삭제 처리
- [ ] **회사**: 미공개 실적, 전략, 계약, 인사 정보가 들어 있는가? → 가상 값으로 치환
- [ ] **고객**: 고객을 특정할 수 있는 정보가 들어 있는가? → "고객A" 등으로 치환
- [ ] **권한**: 이 자료를 외부 서비스에 올릴 권한이 나에게 있는가? → 모르면 올리지 않기

## 치환 예시

| 원본 | 치환 |
| --- | --- |
| 김민지 대리 (010-1234-5678) | 담당자A |
| 6월 매출 3.2억 | 6월 매출 X억 (또는 임의 값) |
| (주)실제거래처명 | 거래처B |
| 계약 단가 4,500원 | 단가 N원 |

> 구조만 유지되면 AI의 도움 품질은 거의 떨어지지 않습니다.
> "치환 후 입력 → 결과에 실제 값 복원"이 안전한 기본 습관입니다.
