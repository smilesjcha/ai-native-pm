# 03. Claude 무료/유료 활용 범위

핵심 표현: **"무료로도 충분히 시작할 수 있고, 유료·연동형 환경에서는 업무 자동화의 범위가 넓어진다."**

## 무료 계정으로 가능한 실습 범위

무료 플랜은 세션 기반 사용량 제한이 있으며 5시간마다 재설정된다. 메시지 수는 수요·프롬프트 길이·파일 길이·대화 길이에 따라 달라진다. (Claude Help Center)

| 구분 | 무료 계정 기준 가능 실습 | 강의 적용 |
| --- | --- | --- |
| 회의록 정리 | 짧은 회의 메모 → 요약·결정사항·액션아이템 | 직접 실습 |
| 보고서 초안 | 업무 상황 기반 보고서 구조·초안 | 직접 실습 |
| 이메일 작성 | 요청/회신 메일, 협업 메시지 톤 개선 | 직접 실습 |
| 자료 정리 | 짧은 텍스트 → 핵심·쟁점·후속 액션 | 직접 실습/선택 |
| 아이디어 도출 | 기획 아이디어 발산·우선순위 | 선택 실습 |
| Markdown/표 | Notion 복붙용 표·체크리스트·회의록 포맷 | 직접 실습 |

코드 실행·파일 생성 기능은 Free 포함 전 플랜에 제공되어 자연어로 Excel·PPT·Word·PDF 생성이 가능하지만, 사용량 제한·기능 노출 여부·브라우저 환경 차이를 고려해 참여자 실습은 텍스트·Markdown·CSV 중심으로 운영한다.

## 유료/확장 환경에서 시연할 내용

Pro는 월 $20, Max는 월 $100/$200. Pro는 무료 대비 세션당 최소 5배 사용량이지만 역시 세션·주간 제한이 있다.

| 구분 | 시연 내용 | 운영 방식 |
| --- | --- | --- |
| Claude for Excel | 데이터 요약, 계산 열 추가, 인사이트, 표 구조 개선 | 강사 시연 |
| Claude for PowerPoint | 슬라이드 구성안, 메시지 정리, 기존 덱 수정 | 강사 시연 |
| Claude for Word | 초안 수정, 문장 다듬기, 문서 질의응답 | 강사 시연 |
| M365 앱 간 연동 | Excel 데이터 → PPT/Word 문서화 | 강사 시연 |
| Skills | 반복 업무 방식·문서 스타일·조직 템플릿의 재사용 | 개념 소개 + 시연 |
| MCP/Connectors | Google Drive·Slack·Notion·파일 시스템 연결 | 개념 소개 + 시연 |
| Claude Cowork/agentic | 로컬 파일 접근, 코드 실행, 장시간 작업, 산출물 생성 | 고급 시연/사례 |
| rhwp/HWP 처리 | HWP/HWPX 읽기, 텍스트 추출, 템플릿 업데이트 가능성 | 강사 시연 (참여자 실습 제외) |

- Claude for Microsoft 365: Excel·PowerPoint·Word·Outlook 안에서 열린 파일을 읽고 수정하는 흐름 제공. MCP connectors·Skills·파일 업로드 지원.
- Claude for Word는 Pro·Max·Team·Enterprise 베타 제공.
- MCP: AI 앱을 로컬 파일·DB·검색·워크플로 등 외부 시스템과 연결하는 오픈소스 표준(2024 공개, 2025 원격 MCP 기반 Integrations 확장).
- Skills: 업무 수행 방식·스크립트·리소스를 폴더로 묶어 필요할 때 불러오는 구조. 문서 생성 작업에도 활용.
- rhwp: Rust + WebAssembly 기반 오픈소스 HWP/HWPX 뷰어·에디터. rhwp-python은 HWP/HWPX 동시 지원(Python 3.10+). 실무 적용 전 한컴 호환성·서식 유지·표/이미지 안정성 검증 필요.
- Claude Cowork: 로컬 파일 접근·코드 실행·산출물 생성·장시간 작업 지원. Claude Desktop + 유료 구독 필요 → 시연/발전 방향 소개로만 다룬다.
