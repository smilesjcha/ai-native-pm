# 안전한 AI 활용 Do & Don't

## Don't — 절대 입력하지 않기

| 구분 | 예시 |
| --- | --- |
| 개인정보 | 주민번호, 전화번호, 주소, 계좌, 이력서 원본(실명 포함) |
| 고객정보 | 고객 명단, 연락처, 상담 기록, 구매 이력 |
| 기업 내부정보 | 미공개 매출·재무, 인사평가, 계약서, 내부 전략 문서 |
| 보안자료 | 비밀번호, API 키, 사내 시스템 접속 정보 |
| 타인 저작물 | 유료 자료 전문, 저작권 있는 문서 통째 입력 |

## Do — 이렇게 사용하기

- 실제 데이터 대신 **구조가 같은 가상 데이터**로 바꿔 입력한다.
  (예: 고객명 → "고객A", 매출 → 임의 숫자)
- 회사 자료를 다뤄야 하면 **회사가 승인한 AI 환경**(기업용 계정)인지 먼저 확인한다.
- AI 결과물은 **초안**으로 취급하고, 사실·숫자·이름을 반드시 검증한다.
- 중요한 의사결정·대외 커뮤니케이션은 사람이 최종 확인한다.
- 회사의 AI 사용 가이드라인이 있다면 그것이 우선이다.

## 환각(지어내기) 대응 3원칙

1. **근거 요청**: "이 내용의 근거를 함께 제시해줘. 모르면 모른다고 말해줘."
2. **확인 필요 표시**: "불확실한 내용은 '확인 필요'로 표시해줘."
3. **원문 대조**: 숫자·날짜·인용은 원문/원본 데이터와 직접 비교한다.

> AI가 "내 의견·결정이 아닌 것을 사실처럼 말하는" 문제는
> 프롬프트에 검증 기준을 넣고(위 1·2), 결과를 원문과 대조(3)하는 것으로 줄일 수 있습니다.
