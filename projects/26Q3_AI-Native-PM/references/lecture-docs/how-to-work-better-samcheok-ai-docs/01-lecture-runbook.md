합계 180분. 강의 장소 및 대면·온라인 방식은 운영기관과 협의 중이며, 장표와 안내에서 확정 표현을 쓰지 않는다.

## 진행 원칙

1. 핵심 실습은 ChatGPT 무료 웹 계정과 복사·붙여넣기만으로 진행한다.
2. 실제 회사·고객·개인 정보를 입력하지 않고 한빛문구 교육용 샘플만 쓴다.
3. 결과가 달라도 정상이다. 목차, 숫자, 확인 필요 표기, 마지막 결정 요청만 함께 확인한다.
4. 사용 한도 또는 로그인 문제가 생기면 짝 실습 또는 강사 화면 따라쓰기로 전환한다. 결과 대신 프롬프트를 노트에 저장해도 학습 목표를 달성한다.

## 장표별 진행 메모

`build_pptx/slides_data.py`의 `minutes`와 `note` 필드가 장표별 발화, 질문, 예상 오답, 운영 시각을 담는 단일 원본이다. `06-slide-instructor-notes.md`와 읽기용 PDF에도 같은 안내가 있다. 현장에서는 PPT 발표자 노트 또는 해당 가이드를 함께 연다.

## 구간별 장표

1–13장 15분, 14–24장 25분, 25–36장 40분, 37장 10분, 38–49장 35분, 50–58장 30분, 59–64장 15분, 65–68장 10분이다. 실습 대기는 발화 시간과 합산하지 않고 각 장표의 배정 시간 안에 포함한다.

## 확장 시연 15분

기능 비교와 준비 5분30초, 진행표 설명 1분, 파일 작업·검토 시연 6분30초, 선택 기준 정리 2분이다. 생성 시간이 길어지면 4분 시점에 사전 제작 예시로 전환하고, 그 예시를 라이브 생성 결과라고 설명하지 않는다.
