# 시작 가이드

## 오늘 만들 결과

1. 신제품 문의 증가 상황을 1페이지 주간 보고서로 정리합니다.
2. 신규 입사자 정보 중복 입력 문제를 1페이지 실행 기획서로 만듭니다.
3. 부서장 관점에서 근거, 누락, 실행 주체, 결정 요청을 검수합니다.

## 준비

- 브라우저에서 ChatGPT 웹을 엽니다. 무료 계정으로 충분합니다.
- 새 대화를 시작합니다. 기존 업무 대화에는 교육용 문장을 섞지 않습니다.
- 각 폴더의 `*-prompt.md`를 열어 회색 코드 영역 전체를 복사합니다.

## 요청 6요소

좋은 요청은 아래 여섯 가지를 한 번에 알려줍니다.

| 요소 | 무엇을 적나 | 예 |
| --- | --- | --- |
| 역할 | 어떤 관점으로 쓸지 | 실무 문서 편집자 |
| 목적 | 문서로 무엇을 결정할지 | 지원 인력 연장 여부 결정 |
| 독자 | 누가 읽는지 | 팀장·부서장 |
| 자료 | 이미 확인된 정보와 가정·확인 필요 | 응답 시간 2.4시간에서 4.1시간 |
| 형식 | 문서의 뼈대 | 목적, 현황, 원인, 조치, 계획, 요청 |
| 검증 | 단위·분량·금지 사항 확인 | 시간 단위, 1페이지, 근거 없는 숫자 금지 |

`자료`에는 사실, 가정, 확인 필요를 함께 적습니다. `검증`에는 단위, 분량, 금지 사항처럼 결과를 확인할 기준을 적습니다.

## Markdown과 PDF 사용법

Markdown은 제목, 표, 목록을 간단한 기호로 표시하는 사람이 읽을 수 있는 가벼운 문서 형식입니다. 파일 확장자 `.md`는 Markdown 문서임을 뜻하며 메모장, VS Code 같은 편집기에서 열 수 있습니다. `.md`는 문장을 복사해 AI 대화에 붙여넣거나 직접 수정하는 원본이고, PDF는 편하게 읽고 인쇄하기 위한 보조본입니다. 두 파일의 내용은 같으므로 목적에 맞게 열어 사용하세요.

## 사실과 가정을 나누는 법

- **사실**: 제공받은 메모나 데이터에서 확인된 내용입니다.
- **가정**: 목표치, 예상 효과, 추정 원인처럼 확인 전 판단입니다. 반드시 `가정`이라고 씁니다.
- **확인 필요**: 원인·규모·담당자가 자료에 없을 때 남기는 표지입니다.

예: `평균 응답 시간은 2.4시간에서 4.1시간으로 1.7시간 증가했다.`는 사실입니다. `FAQ가 원인의 70%다.`는 근거가 없으므로 쓰지 않거나 확인 필요로 남깁니다.

## 실습이 막힐 때

1. 답이 길면 `600자 이내로 줄이고 표를 1개만 남겨 주세요.`라고 다시 요청합니다.
2. 사실과 추정이 섞이면 `사실, 가정, 확인 필요를 각 문장 끝에 표시해 주세요.`라고 요청합니다.
3. 무료 사용량 제한 또는 접속 문제가 생기면 종이/메모장에 프롬프트를 작성하고, `TO-BE` 예시와 비교해 검수표를 완성합니다.

## 안전한 사용

실제 고객명, 주민번호, 연락처, 계좌, 인사평가, 계약서, 로그인 정보는 입력하지 않습니다. 회사 기밀은 이름을 바꿔도 입력하지 않습니다. 공개·사용 허용 자료 또는 이번 강의처럼 별도로 만든 가상 샘플만 사용하고, 결과의 사실 여부와 최종 책임은 작성자가 확인합니다.
