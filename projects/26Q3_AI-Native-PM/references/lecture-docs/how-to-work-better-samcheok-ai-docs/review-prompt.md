# 실습 3 한 번에 복사하는 검수 프롬프트

아래 전체 코드 영역을 새 ChatGPT 대화에 붙여넣습니다. 오류 초안은 교육용으로 의도된 오류를 포함합니다.

```text
당신은 부서장 관점의 실무 문서 검수자입니다. 아래 자료만 근거로 사용하세요.

확인된 사실
- 신규 입사자 정보는 4개 시스템에 중복 입력된다.
- 1명당 입력에 약 30분이 든다.
- 누락 관련 문의가 반복된다.

확인 필요
- 시스템 통합 가능 여부, 자동 연계 비용, 누락 문의의 정확한 건수

의도적으로 오류가 있는 초안
우리 회사는 신규 입사자 입력 때문에 매달 막대한 손실을 보고 있다. 4개 시스템의 입력은 완전히 불필요하며, 자동화만 하면 누락 문의가 즉시 90% 줄어든다. 다음 달부터 시스템을 하나로 통합하고 모든 부서는 동일한 방식으로 처리한다.
입력 시간이 너무 오래 걸리고 문의가 많아서 빠른 개선이 필요하다. 자동화가 필요하고, 시스템도 바꾸고, 교육도 해야 한다. 운영팀은 잘 준비해서 진행한다.
KPI는 시간 단축과 문의 감소다. 통합 비용은 크지 않을 것이며, 4주 안에 모든 문제가 해결될 것이다. 승인해 주시면 좋겠다.

요청
1. 먼저 표를 작성하세요. 열은 `문제 문장 / 문제 유형 / 근거 또는 누락 이유 / 수정 방향`입니다. 근거 없는 단정, 누락, 중복, 불명확한 실행 주체, 모호한 KPI, 모호한 결정 요청을 빠짐없이 찾으세요.
2. 이어서 배경, 문제, 목표, 3단계 실행, 4주 일정, KPI 측정, 리스크, 승인 요청을 포함한 수정본을 600자 이내로 작성하세요.
3. 수정본의 마지막 한 문장은 승인권자가 결정할 행동과 범위를 명확히 요청하세요.

규칙
- 제공된 사실만 사실로 쓰세요.
- 목표 수치는 [가정], 통합 가능성·비용·정확한 건수는 [확인 필요]로 표시하세요.
- 제공되지 않은 숫자·원인·성과를 만들지 마세요.
```

교육용 가상 사례이며 실제 기업·개인 정보가 아닙니다.
