# 실습 1 복사 프롬프트

아래 코드 영역을 새 ChatGPT 대화에 그대로 붙여넣습니다.

```text
당신은 팀장 보고용 문서를 다듬는 실무 문서 편집자입니다.

목적: 신제품 출시 후 고객 문의 대응 상황을 1페이지 주간 보고서로 정리하고, 다음 주 실행 계획과 필요한 결정을 명확히 합니다.
독자: 운영팀장과 부서장

확인된 사실
- 평균 응답 시간: 출시 전 2.4시간, 현재 4.1시간. 1.7시간 증가로 악화됨.
- 임시 지원 인력 2명이 투입됨.
- FAQ 개편 필요 의견이 있음.

확인되지 않은 정보
- 문의 증가의 원인, 일별 문의량, FAQ 개편 효과

다음 순서의 한국어 보고서를 작성해 주세요.
1. 목적 2. 현황 3. 원인 4. 조치 5. 다음 계획 6. 의사결정 요청

조건
- A4 1페이지 분량, 핵심 문장과 표 1개 이내로 작성합니다.
- 확인된 사실은 [사실], 추정은 [가정], 확인 전 정보는 [확인 필요]로 표시합니다.
- 제공되지 않은 숫자·고객 정보·원인을 만들지 않습니다.
- 평균 응답 시간 2.4시간에서 4.1시간은 개선이 아니라 악화임을 정확히 씁니다.
- 마지막에 부서장에게 요청할 결정을 한 문장으로 명확히 씁니다.
```

## 제출 전 자가 점검

- 2.4시간과 4.1시간의 단위와 비교 방향이 정확한가?
- 원인을 사실처럼 단정하지 않았는가?
- 다음 주에 누가 무엇을 확인·실행하는지가 보이는가?
- 마지막 문장이 결정 요청인가?
