# 재사용 프롬프트 템플릿

대괄호 안을 실제 업무의 비식별 정보로 바꿔 사용합니다. 확인되지 않은 숫자는 넣지 않습니다.

## 1페이지 보고서

```text
당신은 [독자]가 빠르게 결정할 수 있도록 문서를 다듬는 실무 편집자입니다.
목적은 [결정 목적]입니다. 독자는 [독자]입니다.

확인된 사실: [사실 1], [사실 2]
확인 필요: [원인/수치/담당자]

목적, 현황, 원인, 조치, 다음 계획, 의사결정 요청 순서로 A4 1페이지 한국어 보고서를 작성해 주세요. 사실은 [사실], 추정은 [가정], 확인 전 정보는 [확인 필요]로 표시하세요. 제공되지 않은 숫자나 원인을 만들지 말고, 마지막 문장은 [승인권자]에게 요청할 결정을 명확히 쓰세요.
```

## 실행 기획서

```text
당신은 [문제]의 실행안을 만드는 기획자입니다. 독자는 [승인권자]입니다.
사실: [현재 방식], [문제], [측정된 수치]
확인 필요: [기술/비용/규모]

배경, 문제, 목표, 대상, 3단계 실행, [기간] 일정, KPI 측정, 리스크, 승인 요청 순서로 A4 1페이지 기획서를 작성해 주세요. 목표 수치는 [가정]으로 표시하고, 각 실행에는 책임 주체와 산출물을 넣으세요. 기준값이 없으면 착수 시 측정한다고 쓰세요.
```

## 상사 관점 검수

```text
아래 문서를 부서장 관점에서 검수해 주세요. 표로 '문제 문장 / 문제 유형 / 근거 또는 누락 / 수정 제안'을 제시한 뒤, 600자 이내 수정본을 작성하세요. 근거 없는 단정, 누락, 중복, 불명확한 실행 주체, 모호한 결정 요청을 우선 확인하세요. 제공되지 않은 사실은 만들지 마세요.

[검수할 문서 붙여넣기]
```

## 짧은 재요청 문장

- `사실, 가정, 확인 필요를 문장 끝에 표시해 주세요.`
- `보고서의 마지막 문장을 승인 요청 한 문장으로 고쳐 주세요.`
- `내용은 유지하고 600자 이내로 줄여 주세요.`
- `표의 항목이 실제 메모와 일치하는지 검수해 주세요.`
