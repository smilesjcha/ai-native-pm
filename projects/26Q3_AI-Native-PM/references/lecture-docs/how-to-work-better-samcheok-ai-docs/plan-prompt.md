# 실습 2 복사 프롬프트

```text
당신은 운영 개선 실행안을 1페이지로 정리하는 기획자입니다.

독자: 운영 책임자와 승인권자
목적: 신규 입사자 정보의 중복 입력과 누락 문의 문제를 줄이기 위한 4주 실행 기획서를 만든다.

확인된 사실
- 신규 입사자 정보를 4개 시스템에 중복 입력한다.
- 1명당 약 30분이 든다.
- 누락 관련 문의가 반복된다.

확인되지 않은 정보
- 시스템 통합 가능 여부, 자동 연계 비용, 누락 문의의 정확한 건수

다음 항목을 이 순서로 포함한 한국어 실행 기획서를 작성해 주세요.
배경, 문제, 목표, 대상, 3단계 실행, 4주 일정, KPI 측정 방법, 리스크, 승인 요청

조건
- A4 1페이지 분량으로 작성합니다.
- 목표 숫자는 반드시 [가정]으로 표시하고 실제 성과처럼 쓰지 않습니다.
- KPI는 `입력 시작부터 종료까지 소요 분`과 `동일 기간·동일 대상에서 접수된 누락 문의 건수`로 쓰고, 기준값이 없으면 '착수 시 기준값 측정'이라고 씁니다.
- 3단계 실행에는 책임 주체와 산출물을 넣습니다.
- 4주 일정은 표로 간단히 씁니다.
- 시스템 통합과 비용은 [확인 필요]로 남기고 단정하지 않습니다.
- 마지막 한 문장은 승인권자가 결정할 내용을 명확히 요청합니다.
```

## 제출 전 자가 점검

- 4개 시스템, 약 30분, 누락 문의 반복이라는 사실이 빠지지 않았는가?
- 목표가 가정으로 표시됐는가?
- 매주 담당자와 산출물이 있는가?
- 승인 요청이 행동과 범위를 구체적으로 말하는가?
