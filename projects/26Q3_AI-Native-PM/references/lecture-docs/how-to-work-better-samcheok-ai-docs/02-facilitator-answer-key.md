# 강사용 정답과 대체 동선

## 실습 1 정답 기준

- 숫자는 평균 응답 시간 `2.4시간 → 4.1시간`, 임시 지원 `2명`만 사용한다.
- 4.1시간은 2.4시간보다 늘어난 것이며 서비스 악화 방향이다.
- 원인은 단정하지 않는다. 문의 유형, 시간대, 인력 배치 자료는 `확인 필요`다.
- 마지막에 FAQ 개편 범위 및 담당 확인 같은 결정 요청을 둔다.

## 실습 2 정답 기준

- 사실: 4개 시스템, 1인 약 30분, 누락 문의 반복.
- 목표 수치는 가정이다. 측정 방식과 기준선을 확인하기 전에는 성과로 쓰지 않는다.
- 3단계는 현황 확인, 입력 항목 정리, 시범 운영·정착 순서다.
- 4주 일정은 담당·산출물이 있어야 하고, 승인 요청은 범위와 담당자 지정이다.

## 실습 3 정답 기준

검수 표에서 근거 없는 단정, 빠진 기준선, 중복, 실행 주체·기한 부재를 잡는다. 수정본은 600자 이내이며 마지막 한 줄에 결정 요청을 쓴다. 실습자는 `03-review/review-prompt.md`의 사실 목록·오류 원문·검수 지시가 모두 포함된 블록을 복사한다. 검수표와 수정본 두 가지를 저장해야 완료다.

| 의도적 오류 문장 | 판단 | 수정 방향 |
| --- | --- | --- |
| 매달 막대한 손실 | 손실 자료 없음 | 삭제 또는 비용 확인 필요 |
| 누락 문의가 즉시 90% 감소 | 효과 근거 없음 | 삭제, 목표값은 기준 확인 후 가정 |
| 다음 달 시스템 하나로 통합 | 가능 여부·범위 미확정 | 4주 현황 확인·표준화·시험 제안 |
| 개선·자동화·시스템 변경·교육 반복 | 실행 순서 없음 | 3단계 담당·산출물로 정리 |
| 운영팀은 잘 준비해서 진행 | 실행 주체 불명확 | 운영 담당·인사·운영·운영 책임자 역할 제안 |
| KPI는 시간 단축과 문의 감소 | 측정 기준 없음 | 시작~종료 분, 동일 기간·대상 문의 수 |
| 비용은 크지 않고 4주 안에 해결 | 비용·효과 단정 | 시스템 제약·비용 확인 필요 |
| 승인해 주시면 좋겠다 | 결정 범위 없음 | 담당자 참여와 시험 대상 선정 요청 |

## 장애 대체 동선

| 상황 | 즉시 전환 | 강사 확인 |
| --- | --- | --- |
| 로그인 불가 | 옆 사람 결과 읽기, 종이에 프롬프트 표시 | 목차와 검수 항목 |
| 무료 사용 한도 | 강사 화면 결과를 문서에 표시 | 사실/가정/확인 필요 |
| 결과가 장문 | `600자 이내, 표 제외`를 추가 | 마지막 요청 문장 |
| 허위 숫자 생성 | `자료에 없는 값은 확인 필요`를 재입력 | 원문 숫자 3개 |
