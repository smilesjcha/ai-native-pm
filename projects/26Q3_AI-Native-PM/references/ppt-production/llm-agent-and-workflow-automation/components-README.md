# PPT Visual Components

강의 장표에서 반복 사용할 수 있는 흑백 아이콘, 기술 브랜드 표식, 글로벌 개발자 발표 참고 이미지를 모은 폴더입니다.

## 폴더 구조

- `icons/lucide/`: 원본 SVG 기능 아이콘
- `icons/png/`: PowerPoint 삽입용 PNG
- `brands/simple-icons/`: 기술 브랜드 원본 SVG
- `brands/png/`: PowerPoint 삽입용 PNG
- `references/`: 공식 사이트에서 내려받은 발표·workflow 참고 이미지
- `manifest.json`: 파일별 출처와 사용 범위

## 사용 원칙

1. 기능 아이콘은 한 장의 핵심 동작을 빠르게 이해시키는 경우에만 사용합니다.
2. 브랜드 표식은 해당 제품·서비스를 실제로 설명하는 장표에서만 사용합니다.
3. 참고 이미지는 출처를 speaker notes에 기록하고, 장식용 배경으로 반복 사용하지 않습니다.
4. 본문 palette는 black·white·gray·navy·blue를 유지합니다. 외부 참고 이미지만 원본 색을 유지합니다.
5. 같은 아이콘을 연속 장표에 반복하지 않습니다.
