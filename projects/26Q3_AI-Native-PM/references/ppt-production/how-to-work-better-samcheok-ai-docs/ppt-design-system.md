# PPT 디자인 시스템

## 의도

문서 작성 실습을 주인공으로 두는 편집형 강의 자료다. 화면을 여백이 있는 종이처럼 쓰고, 중요한 문장과 실제 문서의 구조를 크게 보여 준다. 반복 카드 대신 문서 확대, 여백형 설명, 표, 시간선, 대화형 프롬프트, 검수 흔적을 번갈아 사용한다.

## 토큰

| 항목 | 값 | 용도 |
| --- | --- | --- |
| 잉크 | `#17212B` | 제목, 본문 |
| 먹색 | `#0B1F33` | 챕터, 표 머리말 |
| 청록 | `#007C83` | 핵심 행동, 강조선 |
| 살구 | `#FFCD8A` | 주의, 가정 |
| 연회색 | `#F2F5F7` | 문서 배경 |
| 오프화이트 | `#FBFCFA` | 기본 배경 |
| 오류색 | `#B42318` | 의도적 오류, 위험 |
| 한글 글꼴 | `Apple SD Gothic Neo` | 전 페이지 |

모든 값은 `build_pptx/theme.py`에 같은 이름으로 정의한다. 코드에서 색상, 글꼴 크기, 여백을 직접 지정하지 않는다.

## 타이포그래피와 안전 영역

- 표지 제목 40pt, 슬라이드 제목 32pt, 장표 핵심 문장 27pt
- 일반 본문·복사 프롬프트·문서 예시·표 본문 20pt, 보조 소개 17pt, 주석 12pt
- 가로 13.333in × 세로 7.5in, 좌우 0.62in, 주요 내용 상하 0.5in 안전 여백. 하단 과정명·쪽수는 별도 주석 영역에 둔다.
- 제목 아래 얇은 청록선, 하단에는 과정명과 슬라이드 번호를 둔다.
- 모든 배치 영역, 셀·도형 안쪽 여백, 줄간격, 크롭 비율은 `theme.py`의 의미 있는 토큰으로 관리한다.
- 문서와 프롬프트는 줄간격 1.05, 안쪽 여백 0.16in을 사용한다. 빈 줄은 8pt 간격으로 두어 본문 크기를 줄이지 않는다.
- 표는 가로 패딩 0.10in, 세로 패딩 0.08in, 줄간격 1.0으로 설정한다. 셀 안쪽 마지막 줄과 하단 테두리 사이의 여유를 렌더에서 확인한다.
- 기본 도형 효과를 비워 테마에서 자동으로 들어오는 그림자·입체 효과를 제거한다.
- 파일명은 문서·프롬프트 하단의 독립된 12pt 캡션 영역에 쓴다. 실습 대기 화면은 20pt 안내문 4~5줄을 담을 높이를 확보한다.

## 문서 표기

- 사실: 먹색 텍스트. 제공된 원문에 있는 정보만 쓴다.
- 가정: 살구 배경 및 `[가정]` 표기.
- 확인 필요: `확인 필요`라는 문구를 명시한다.
- 의도적 오류: 오류색 라벨 및 바로 뒤 정답 검수표를 배치한다.

## 이미지와 근거

- 사진 대신 실제 교육용 문서 확대와 고해상도 Mermaid 흐름도를 주 시각물로 사용한다.
- 강사 사진은 본인 제공 프로필 자산으로 한 번만 사용한다. 과거 직함이 적힌 왼쪽 57%는 PowerPoint 네이티브 크롭으로 숨기고, 오른쪽 인물 영역의 원래 종횡비를 유지한다.
- 실제 1페이지 PDF를 보여주는 미리보기는 왼쪽에 세로 약 5in으로 비율을 유지해 넣고, 오른쪽 20pt 본문으로 읽어야 할 문장을 확대한다.
- 업무 사진은 세로 약 4.9in으로 원본 비율을 유지하고, 오른쪽에 문서 판단 질문을 배치한다. 사진 자체를 성과나 특정 사건의 증거로 쓰지 않는다.
- 제품 기능은 슬라이드 60의 OpenAI 공식 도움말 URL과 `docs/04-sources.md`에 출처를 남긴다.
