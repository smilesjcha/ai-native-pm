# 제작 기록과 사용 범위

## 제작 방식

- 2026-09-11, 사용자가 요청한 새 Codex 작업에서 독립 강의 폴더를 만들었다.
- 시작 요청 설정은 `gpt-5.6-terra / high`다. 2026-09-11 사용자의 “PPT로 제작 완료해줘” 입력 직전에 실행 컨텍스트의 `model_switch` 안내가 GPT-6 기반으로 변경되었음을 알렸다. 부모 작업이 해당 제작 작업의 세션 `turn_context`를 확인한 결과 후속 설정은 `gpt-6-astra / ultra`였다. 이 전환 이전에 부모가 보낸 후속 메시지에는 모델 override가 없었고, 제작 작업도 전환을 요청하는 도구를 호출하지 않았다. 전환을 누가 어떤 UI 동작으로 시작했는지는 확인하지 못했다. 이후 레이아웃·출처 검수용 서브에이전트는 당시 실행 설정을 상속했다. 전체 제작을 Terra 한 모델만 수행했다고 주장하지 않는다.
- 설계 문서, `slides_data.py`, `theme.py`, `layouts.py`, `build.py`로 PPT를 재현한다. 강의 폴더 밖 원본 자료는 읽기·복사만 했다.
- 강의 제작과 교육용 모범 답안 작성은 무료 ChatGPT 웹에서 수강생 실습을 실제 실행한 기록이 아니다.
- 장표의 문서 예시는 교육용 가상 결과다. Codex 시연의 사전 제작 결과를 사용할 경우 실시간 결과와 구분해서 안내한다.

## 하네스 적용

원문 자료, 요청, 파일별 완료 기준, 실패 시 대체 경로, 사람의 검수 기록을 함께 보관했다. 각 장표에는 설명·질문·예상 오답·운영 시각을 넣었다. 초기 완성 문서 두 개는 실제 1페이지 PDF를 렌더한 이미지이며, 수업 중 확대 예시는 같은 자료의 핵심 요약임을 표시한다.

## 공개 배포 범위

공개 배포 ZIP에는 실습용 가상 자료·강의 산출물·재빌드 코드·출처 설명을 넣는다. 연락처가 있는 강사 프로필 원본 PDF, 메일 주소와 식별자가 있는 원문 브리프, 행정 자료는 포함하지 않는다. 원본 근거는 이 작업 폴더의 `docs/sources/`와 `docs/00-source-brief.md`에 제작 참고용으로만 남는다.

## 시행 전 확인

- 운영기관과 장소·대면/온라인 방식, 화면 공유·인터넷 환경을 확정한다.
- ChatGPT 무료 로그인과 현재 사용 한도 안내를 확인한다.
- 강사 Codex 계정에서 요청된 모델·추론 설정을 확인하고, 사전 제작 결과를 예비 동선으로 연다.
- 무료 계정 사용 한도가 생기면 결제를 유도하지 않고 제공된 모범 결과를 검수하는 활동으로 전환한다.
