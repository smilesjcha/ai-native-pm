# Week 01 Visual System — BLACK / WHITE / NAVY / BLUE

이 문서는 80장으로 구성한 Week 01 강의안의 시각 구현 기준이다. 특정 브랜드의 로고나 UI를 복제하지 않고, 한국 패션 에디토리얼의 강한 흑백 대비·날카로운 그리드·절제된 파란색을 기술 강의에 맞게 번역한다. 전체 16주 공통 제작 원칙은 [PPT 제작 가이드](PPT_PRODUCTION_GUIDELINE.md)를 따른다.

## 시각 원칙

1. 한 장에는 `개념·비교·근거·실행·평가` 가운데 하나의 역할만 둔다.
2. 이미지는 장식이 아니라 사례·증거·맥락일 때만 사용한다.
3. 흰색·밝은 회색과 검정·네이비 배경을 구간에 맞게 교대해 호흡을 만든다.
4. 둥근 카드형 대시보드 대신 선, 면, 숫자, 간격, 활자로 위계를 만든다.
5. 같은 레이아웃 실루엣을 세 장 연속 사용하지 않는다.
6. 파랑은 위치나 순서가 아니라 현재 변수·운영 증거·평가 결과·운영 결정처럼 의미가 있을 때만 사용한다.
7. 매주 초반의 로드맵은 같은 정보 구조를 유지하고, 해당 주차만 의미 기반 파란색으로 강조한다.

## 색상

| Token | Hex | 역할 |
|---|---|---|
| `BLACK` | `#050505` | 표지, 강한 구분 장표 |
| `INK` | `#191919` | 제목, 본문, 기본 도식 |
| `WHITE` | `#FFFFFF` | 기본 배경, 어두운 면의 본문 |
| `PAPER` | `#F7F8FA` | 밝은 보조 면과 화면 호흡 |
| `NAVY` | `#0B1F3A` | 구분 장표와 구조 강조 |
| `BLUE` | `#2563EB` | 현재 변수, 운영 증거, 평가 결과, 운영 결정 |
| `BLUE_SOFT` | `#E0F0FE` | 약한 비교 면과 annotation |
| `GRAY` | `#667085` | 보조 본문 |
| `HAIRLINE` | `#D0D5DD` | 구분선 |

- 주황·빨강·노랑·초록·보라·시안은 장식 색으로 사용하지 않는다.
- gradient, glow, glassmorphism, 다색 module coding을 사용하지 않는다.
- 실제 제품 화면과 screenshot은 원래 색을 유지하며 색상 overlay를 씌우지 않는다.
- 같은 위계의 항목은 같은 색과 무게를 유지한다.
- 마지막 항목·오른쪽 열·마지막 슬라이드라는 이유만으로 파랑을 적용하지 않는다.

## Typography

- 한국어: `AppleGothic` 또는 최종 변환 환경에서 확인된 일반 고딕체
- 숫자·영문: `Helvetica Neue`
- 코드: `Menlo`

| 요소 | 최소 | 권장 |
|---|---:|---:|
| 표지 제목 | 54pt | 58–64pt |
| Section 제목 | 44pt | 46–50pt |
| 일반 제목 | 38pt | 40–44pt |
| 중간 제목·핵심 수치 | 24pt | 26–32pt |
| 본문 | 18pt | 20–24pt |
| 표 Cell | 17pt | 18–20pt |
| Code | 16pt | 17–19pt |
| Micro label·footer | **14pt** | 14–16pt |

- 화면에 보이는 모든 텍스트의 절대 최소 크기는 14pt다.
- `shrinkText`로 overflow를 숨기지 않는다. 문장 축약, 정보 통합, 장표 분할, 레이아웃 변경 순서로 해결한다.
- 제목은 2–8단어의 한 줄 명사형을 기본값으로 한다.
- 표지 제목·장표 제목·부제에는 `합니다`, `됩니다`, `있습니다`, `~다` 같은 문장형 종결어미와 마침표를 쓰지 않는다.
- 표지 부제는 설명 문장 대신 `기술 · 과업 · 산출물` 키워드 조합으로 구성한다.

## Layout

- Canvas: 16:9, 1280 × 720
- 안전 여백: 좌우 64px, 상단 40px, 하단 42px
- 기본 구조: 12-column grid, column gap 24px, section gap 32px
- 모서리: 0–4px
- 기본 정렬: 제목·본문·하단선의 왼쪽 기준선 통일
- 텍스트 상자와 구분선·색상 면 경계 사이 안전 간격: 모든 방향 최소 12px

80장 전체에서 다음 실루엣을 내용에 맞게 교차 사용한다.

1. 최소 표지와 dark section divider
2. 대형 명제와 단일 수식
3. 좌우 분류 비교와 matrix
4. 세로형 `01–05` 단계 목록
5. Timeline, ladder, cost staircase
6. 서비스 개선 사이클과 swimlane
7. Trace anatomy와 schema specimen
8. 실제 UI 확대와 번호 annotation
9. Terminal command와 expected signal
10. Failure–recovery map과 application checkpoint

단계명은 2–6어절, 설명은 두 줄 이하로 제한한다. 시간·의존 관계가 실제로 있을 때만 화살표를 사용한다. 긴 단계명은 가로 한 줄로 이어 붙이지 않고 번호와 명시적 개행으로 읽기 순서를 만든다.

- 두 줄 이상을 의도한 제목 외 텍스트는 작성 데이터에 `\n`을 넣어 의미 단위의 개행을 고정한다.
- 표와 단계 목록의 행 높이는 가장 긴 셀의 개행 수와 글자 크기에 맞춰 가변적으로 계산한다.
- 행마다 내용 분량이 다른 표에 하나의 고정 높이를 일괄 적용하지 않는다.
- 구분선과 색상 면은 텍스트를 누르지 않도록 최소 12px의 안쪽·바깥쪽 안전 간격을 유지한다.

기술 용어는 첫 등장에 한글 용어, 영어 전체 이름과 약어를 함께 둔다. `CTX`, `EVAL`, `GOVERN` 같은 임의 축약은 사용하지 않는다. 영어 단어와 한글 어절이 중간에서 끊기면 글자 크기를 줄이는 대신 폭·문구·레이아웃을 조정한다.

## 주차 로드맵 모듈

매주 강의안의 초반에는 수강생이 현재 위치와 다음 산출물을 즉시 확인할 수 있는 공통 모듈을 둔다. Week 01의 80장 구성에서는 표지 다음인 2–7장에 현재 주차, 16주 일정, 포트폴리오 로드맵, 기획서 제출 패키지, 교수 설계 리뷰, 공휴일 주차 운영을 배치한다.

전체 과정은 대면 수업 없이 온라인으로 운영한다. 로드맵의 기본 진행 표기는 `실시간 온라인`이며, 공휴일 녹화영상·8주차 온라인 제출·평가·16주차 실시간 온라인 발표를 서로 다른 운영 상태로 구분한다.

### 정보 순서

1. `현재 주차`: 01–16 주차 레일과 해당 주차의 학습 목표·산출물
2. `전체 일정`: 날짜, 진행 방식, 핵심 주제, 산출물을 포함한 16주 요약
3. `누적 로드맵`: 문제 정의부터 기획서 제출, 구현·검증, 발표까지의 연결
4. `이번 주 계약`: 실습 완료 조건과 다음 제출물로 이어지는 증거

### 하이라이트 규칙

- 해당 주차의 번호·짧은 제목·연결선에만 `BLUE`를 사용한다.
- 지난 주차는 `INK` 또는 `GRAY`, 이후 주차는 `GRAY`와 `HAIRLINE`으로 위계를 낮춘다. 완료 여부를 색만으로 전달하지 않고 `완료`, `현재`, `예정` 텍스트를 함께 쓴다.
- 8주차는 `실시간 수업 없음 · 기말 프로젝트 기획서 온라인 제출·평가`, 16주차는 `실시간 온라인 · 기말 프로젝트 발표`라는 검정 이정표로 유지한다. 중간 또는 마지막 위치라는 이유만으로 파란색을 적용하지 않는다.
- 4주차 `2026.09.25 · 추석`과 6주차 `2026.10.09 · 한글날`에는 `정규 실시간 온라인 강의 대신 녹화 강의영상 업로드`를 날짜와 함께 명시한다. 두 주차를 `휴강`으로 표기하지 않는다.
- 공휴일·제출·발표 상태는 아이콘이나 색만으로 구분하지 않고 진행 방식과 행동을 텍스트로 표기한다.

### 반복 사용 규칙

- 이후 주차 강의안에서는 슬라이드 구조와 16주 일정 데이터는 유지하고 `현재 주차` 값과 이번 주 계약만 갱신한다.
- 로드맵에는 전체 16주를 모두 유지하되, 한 장의 설명 밀도가 높으면 `4 × 4 일정표`와 `5구간 포트폴리오 지도`로 분리한다.
- 장표 제목은 `1주차의 위치`, `16주 수업 일정`, `기획서 제출 패키지`처럼 명사형으로 작성한다.
- 로드맵의 현재 주차 강조는 장표의 유일한 1차 파란색 초점으로 취급한다. 다른 설명·날짜·장식에는 경쟁하는 파란색 강조를 추가하지 않는다.
- 현재 주차 이동은 장식 변경이 아니라 학습 기록의 상태 변경이다. 발표자 노트에도 해당 주차의 목표, 증거, 다음 이정표를 함께 갱신한다.

## 반복 요소

- `W01 / LLMOPS` micro label
- 초반부의 `01–16` 주차 레일과 `현재 주차` 상태
- 우측 상단 두 자리 slide number
- 1px hairline divider
- 의미 기반 blue rule 또는 작은 square
- section break의 giant index

반복 요소도 14pt 최소 크기와 의미 기반 강조 원칙을 따른다. 장표 번호나 마지막 위치에는 자동 강조를 적용하지 않는다.

## 접근성·배포

- 모든 텍스트와 도형은 PowerPoint에서 편집 가능하게 유지한다.
- dark/light 배경 모두 충분한 텍스트 대비를 확보한다.
- 의미 있는 screenshot에는 대체 텍스트를 지정한다.
- 모든 장표의 발표자 노트에 `[Sources] ... [/Sources]` 블록을 둔다.
- 배포용 표지·공통 푸터·실습 화면에는 특정 대학명, 학교 로고, 학교별 교과목 코드를 사용하지 않는다. 수강 대상은 `대학생·대학원생 대상 통합 LLMOps 강좌`로 표기한다.
- 공개 승인을 받은 역할명 `무신사 Core AI PM × AI 대학원 겸임교수`는 사용할 수 있다. 그 밖의 개인 연락처, 내부 조직명, 내부 사례·지표, API key, 로컬 절대경로는 넣지 않는다.
- 최종본 80장을 모두 같은 판독 크기로 렌더하고 장표 번호별로 1장씩 전수 검수한다. 몽타주는 흐름 확인에만 사용하며 개별 검수를 대체하지 않는다.
- 전수 검수에서는 overflow, 겹침, 명시적 개행, 가변 행 높이, 텍스트와 선·면 사이 12px 안전 간격, 14pt 미만 텍스트, 금지 색상, 동일 레이아웃 3장 연속 여부를 확인한다.
