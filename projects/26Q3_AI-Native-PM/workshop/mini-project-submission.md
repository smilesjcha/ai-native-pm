## 제출물 (파일 4개, 오늘 수업 중 생성)

| # | 제출물 | 어디서 만드나 | 최소 기준 |
|---|--------|--------------|-----------|
| ① | 내 업무 프롬프트 템플릿 카드(v1 이상) + 오류 초안 검수 결과 | 1부 실습(10:25 · 10:58) | 요청 6요소(역할·목적·독자·자료·형식·검증)가 모두 있고, [자료] 칸이 **내 업무**로 채워져 있음(캐치업·오후 v2 반영 가능) |
| ② | **핀테크 서비스 기획서(PRD) 초안 + AI 3관점 리뷰 결과 + 임원용 2-Pager** | 2부 실습(13:25–14:00) | 아래 개인화 기준 충족 · 결론부터 블록 · 성공 지표 3종(Baseline→Target→측정) · 규제·리스크 질문 목록 · `[가정]`/`[확인 필요]` 표기 · 마지막에 요청 사항 |

| ④ | 나의 자동화 워크플로 1장 | 3부 실습 ④(15:50) | A4 시트 5칸 표 완성 + 세 기준 점검(자주·지루·안전) |

## 개인화 기준 (②에 적용)

- **A. 내 서비스**: 5개 핵심 입력(서비스명·타겟 유저·핵심 문제·AI 활용점·성공 기준)을 내 아이디어로 작성 — 회사 실제 수치·내부 정보는 치환.
- **B. 머니핏 변형**: 강사 가상 사례(머니핏)를 따라가되 **타겟·핵심 문제·AI 활용점 중 2개 이상**을 바꾼 버전. 처음이라면 B를 권장.
- 두 경우 모두 문서 상단에 "교육용 가상 사례 · 실제 기업·고객 데이터 미포함"을 한 줄 쓴다.

## 파일 형식·이름

- 형식: PDF 또는 DOCX(채팅 결과를 메모장·Word에 붙여 저장) `[확인 필요: 운영기관 지정 형식]`
- 파일명: `M5_미니프로젝트_[이름]_v1.pdf` (여러 파일이면 `_01프롬프트카드`, `_02기획서패키지`, `_03분석또는회의록`, `_04워크플로` 접미)
- 하나로 합치기 어려우면 ZIP 1개로.

## 제출 전 3분 체크리스트

- [ ] 파일 4개(또는 ZIP)에 ①~④가 모두 있다
- [ ] 기획서 첫 5줄에 결론·지표·요청이 보인다(두괄식)
- [ ] 숫자 옆에 `[가정]` 또는 출처가 있고, 확인 전 정보는 `[확인 필요]`로 남겼다
- [ ] 규제·리스크 섹션이 "컴플라이언스에 물어볼 질문" 형태다(법률 판단을 단정하지 않았다)
- [ ] 실명·연락처·실제 고객·거래·내부 데이터가 없다(치환했다)
- [ ] 문서 상단에 "교육용 가상 사례" 한 줄이 있다

## 강사 운영 메모

- 오프닝(M0)에서 "오늘 산출물 = 미니 프로젝트 제출물"을 먼저 선언하고, 마무리(M13)에서 이 체크리스트로 회수한다.
- 30명 규모: 실습 중 낙오자는 옆사람 페어 + 강사 모범 결과 파일로 최소 기준을 채우게 한다. "프롬프트만 저장해도 ①은 인정".
- 결과가 강사와 다른 것은 정상이며 평가 대상이 아니다 — 구조(목차·표·태그·요청 문장)만 본다.
