※ 교육용 가상 자료 — 실제 기업·상품·조항과 무관. 이 파일은 lab-3-automation-workflow.md의 코드 블록과 동일 내용(MD가 원본). 아래 줄부터 끝까지 전체 복사해 새 대화에 붙여넣기.

역할: 당신은 핀테크 서비스의 퍼널 데이터를 분석해 기획자의 의사결정을 돕는 데이터 분석가입니다.
목적: 가입 → 계좌 연동 → 목표 설정 → 첫 저축 → 30일 활성, 5단계 퍼널의 전환율을 계산하고 가장 큰 이탈 구간과 개선 가설을 찾습니다.
독자: 이 데이터를 처음 보는 서비스 기획자(PM). 임원 보고 자료의 근거로 씁니다.
자료: 첨부한 moneyfit-events.csv (교육용 가상 데이터, 실제 고객 데이터 아님). 첨부 파일만 사용하고, 파일을 실제로 읽어 계산합니다.
데이터 딕셔너리: user_id(가상 사용자 ID) / signup_date(가입일) / age_band(연령대 25-29·30-34·35-39) / channel(유입 채널 app_store·play_store·referral·ad) / event(퍼널 단계 signup → link_account → set_goal → first_saving → d30_active) / event_date(발생일). 한 사용자는 도달한 단계까지만 행이 있습니다.
형식: 한국어로, 아래 순서대로.
1. 데이터 품질 확인: 완전 중복 행과 event_date가 signup_date보다 앞선 행이 있으면 건수를 보고하고 제외합니다.
2. 전체 퍼널 표: 단계 | 고유 사용자 수 | 전체 대비 % | 직전 단계 대비 %
3. 차트 1개: 제목은 결론 문장, 막대 라벨에 사용자 수와 %. 차트를 그릴 수 없으면 텍스트 막대(■)로 대신합니다.
4. 인사이트 3개: 열이 3개인 표 — 근거 숫자(표에서 그대로 인용) | 해석([가정] 표시) | 액션(무엇을 바꾸는가)
검증: 전환율은 행 수가 아니라 고유 user_id 수로 계산하고, 계산 과정(코드)을 보여주세요. 자료에 없는 숫자나 사실은 만들지 말고 [확인 필요]로 표시하세요. 데이터에 없는 원인은 [가정]으로 표시하세요.
