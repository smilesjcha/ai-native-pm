## 2. 시작 전 3분

### 2.1 계정 로그인 — 체크 4개 (09:20까지 마치면 가장 좋음)

- [ ] 내 환경: □ 개인 계정 □ 회사 승인 계정 □ 둘 다 — 오늘 실습은 **개인 계정(1층)** 기준, 가상 데이터만 사용
- [ ] 오늘 실습 도구 1개: □ ChatGPT □ Claude □ Gemini — **무료 웹 계정**으로 충분. 설치·결제·연동 없음
- [ ] 로그인 완료 — 새 대화를 열 수 있는 상태
- [ ] 한도 도달 시 두 번째 도구: □ ChatGPT □ Claude □ Gemini — 무료 플랜은 사용량 한도가 있습니다. 한도에 닿으면 같은 프롬프트를 두 번째 도구에 붙여넣기

로그인은 **오프닝(09:30대) 안전 규칙 장표에서 30초간 현장 확인**합니다. 그 자리에서 안 되면 바로 페어를 지정하니 손을 들어 주세요. 개인 휴대폰 웹 접속 또는 옆 사람과 페어로 진행합니다.

### 2.2 안전 규칙 3줄 (금융권 필수)

1. **실데이터 금지** — 실제 고객·거래·내부 문서·실명·연락처는 오늘 어디에도 넣지 않는다.
2. **치환** — 구조만 남기고 가상 값으로 바꾼다(고객A · N건 · X억 · 제휴사B). 치환 후 입력 → 결과에 실제 값 복원.
3. **검증** — AI 결과는 초안이다. 숫자·규제 조항·상품 조건·경쟁사 기능은 원문과 대조한다.

**입력 전 30초 체크리스트** — 붙여넣기 전에 4가지만: □ 사람(실명·연락처?) □ 회사(미공개 실적·전략·계약?) □ 고객(특정 가능한 정보?) □ 권한(이 자료를 외부 서비스에 올릴 권한이 나에게 있나? 모르면 올리지 않기). 전문과 치환 예시는 `prompt-card-deck.md` 부록 B(= `prompt-templates-fintech.md` §9).

### 2.3 실제 업무 데이터 지참 금지

- 오늘 실습에 필요한 자료는 **전부 이 키트 안에 있습니다**(가상). 회사 문서·엑셀·회의록·고객 자료를 가져오거나 화면에 열어 두지 않습니다.
- "내 업무" 카드를 쓸 때도 회사 원문을 붙이지 않고, `[자료]` 칸에 **치환된 값**만 메모합니다(§2.2 규칙 2).
- 회사 데이터로 다시 쓰는 것은 **회사가 승인한 환경(2층)** 에서, 회사 AI 가이드라인이 정한 범위 안에서만 합니다. 개인정보 컬럼 제거·가명처리 기준은 컴플라이언스 확인이 필요합니다 `[확인 필요]`.

## 5. PDF는 읽기용, MD는 복사용

- **`.md`(Markdown)** 는 복사·붙여넣기·편집용 **원본**입니다. 메모장·텍스트 편집기·브라우저로 열어 코드 블록(회색 상자)을 전체 복사합니다.
- **`.pdf`** 는 읽기·인쇄용 **보조본**입니다. PDF에서 복사하면 줄바꿈·표 구분자(`|`)가 깨질 수 있으니 **붙여넣기는 MD 또는 `.txt`에서** 합니다. 두 파일의 내용은 같습니다.
- **`.txt`** (`prompts-txt/`)는 MD·GitHub가 막힌 회사 노트북·휴대폰용입니다. 메모장으로 열어 첫 안내 줄 아래를 전체 복사합니다.
- 결과를 메모장에 붙였을 때 `#`·`|` 기호가 보이는 것은 깨진 것이 아니라 Markdown 형식입니다. 채팅 화면의 복사 버튼으로 Word·노션에 붙이면 표로 들어갑니다.

## 6. 결과가 달라도 정상

**결과 문장이 강사·옆사람과 달라도 정상입니다.** 우리는 문장이 아니라 아래만 함께 확인합니다.

- **목차** — 내가 `[형식]`에 쓴 순서대로 나왔나 (표가 있으면 열 이름까지)
- **표기** — `[확인 필요]`·`[가정]`이 보이나. **0개면 좋은 결과가 아니라, 자료에 없는 것을 전부 채웠다는 신호**
- **마지막 문장** — 독자에게 요청하는 문장으로 끝났나

숫자도 다를 수 있습니다(예: 데이터 분석에서 이상치 제외 여부에 따라 연동 사용자 385명 또는 387명 — 둘 다 정상). 각 카드의 **결과 체크 3개**만 보고, 실패한 항목에 **재요청 문장 1개**를 넣습니다. 프롬프트를 처음부터 다시 쓰지 않습니다.

| 무료 사용량 한도 도달 | §2.1에서 정한 **두 번째 도구**의 새 대화에 같은 카드를 붙여넣기(리뷰·검수 단계면 오히려 교차 검증). 그래도 안 되면 강사 화면 따라 쓰기. 프롬프트는 한 번에 완성해서 보내면(짧게 여러 번 X) 한도를 아낄 수 있음 |
| 결과가 강사·옆사람과 다름 | **정상.** §6의 목차·표기·마지막 문장(표가 있으면 열 이름)만 확인 |
| 결과에 `[확인 필요]`가 하나도 없음 | 재요청 1번 문장(부록 A)을 넣는다. 그 결과가 오늘 가장 좋은 교재 |
| 결과가 너무 길다 | 재요청 4번(절반으로) — 숫자·`[확인 필요]`·마지막 요청 문장은 유지 |
| 표 대신 문장으로 답함 | "위 내용을 표 1개로만 다시 출력해 주세요. 열: [열 이름들]" |
| AI가 초안을 고쳐 써 버림(검수·리뷰 단계) | "고쳐 쓰지 말고 문제 표만 작성해 주세요. 수정은 제가 합니다." |
| 파일 업로드가 안 됨(Session 3) | P11 **집계표용** 카드를 붙인다(집계표가 프롬프트 안에 들어 있음) |
| PRD가 길어 리뷰 대화에 안 들어감 | 결론부터·성공 지표·규제·리스크 세 섹션만 붙인다 |
| 내 업무가 안 떠오름 | 기본 경로 그대로 — 머니핏 완성본(P01)을 실행하고 재요청(Step 3)에 집중. 내 업무 카드는 캐치업(11:10–11:30)·오후에서 |
| 시간이 부족함 | Step 3(한 번 수정)을 생략하고 Step 2 확인까지만. **프롬프트는 반드시 저장** |

## 9. 교육용 가상 데이터 표기

- 이 키트의 사례(머니핏·핀트리·경쟁 서비스 A·가상 A/B/C사), 설문·퍼널·거래 수치, 회의 메모, 실습 ② 오류 초안의 **조항 번호**는 모두 **교육용으로 만든 가상 자료**입니다. 실제 기업·상품·인물·거래·법 조문과 무관하며, 실제 근거로 인용하지 않습니다.
- `sample-data/`의 CSV·회의 메모는 스크립트로 생성한 가상 데이터로 개인정보 컬럼이 없어 **외부 AI 서비스에 올려도 되는 파일**입니다. 같은 형식이라도 실제 회사 데이터는 회사가 승인한 환경에서만 다룹니다.
- 표기 규칙: 수치는 `[가정]`, 확인 전 정보는 `[확인 필요]`, 규제 관련 문장은 "컴플라이언스 확인 필요". 이 표기가 결과에 **남아 있는 문서가 정직한 초안**입니다.
- 이 키트는 법률 자문이 아닙니다. 규제 체크리스트는 "컴플라이언스에 무엇을 물어볼지"까지만 다룹니다.
