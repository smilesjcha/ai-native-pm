# Claude Context — 26Q3_Fastcampus-Lecture

## 프로젝트 목적
패스트캠퍼스 "AI Native PM" 특강 자료 제작. 강의(30분) + 실습(60분) 구성.

## 핵심 컨텍스트
- 대상: 예비 PM, 주니어 PM, 비개발 직군 (AI PM에 관심 있는 사람)
- 데모 서비스: "오늘의 점심 메이트" (AI 점심 추천)
- 실습 도구: Manyfast.io (PRD 생성), Claude Code (프로토타입)
- 언어: 한국어 기본, 기술 용어 영어 병기

## 제약 사항
- 프로토타입은 단일 HTML 파일 (외부 API 호출 없음)
- 실습은 60분 내 완료 가능해야 함
- 참가자의 기술 수준이 낮을 수 있으므로 단순하게 유지
