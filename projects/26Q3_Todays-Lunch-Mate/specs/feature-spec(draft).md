## 1. AI 기반 맞춤형 식당 추천

**설명**
사용자의 현재 기분(선택형), 예산(가격대), 그리고 과거 이용 기록 및 선호도를 바탕으로 AI(Claude Haiku)가 3가지의 최적화된 점심 메뉴/식당을 추천합니다.

**주요 흐름**
1. 사용자가 기분·예산·(선호도) 입력 완료
2. 시스템이 Claude Haiku API로 추천 요청 전송
3. AI가 3개의 맞춤 추천 결과 반환 (식당명, 메뉴, 추천 이유)
4. 사용자는 추천 중 하나를 선택하거나 재추천 요청

**관련 KPI**: AI 추천 수락률 60% 이상

---

## 2. 사용자 정보 입력 및 관리

**설명**
사용자가 자신의 기분(예: 든든한, 깔끔한, 매콤한 등)과 점심 예산(예: 1만원 미만, 1~1.5만원, 1.5만원 이상 등)을 선택하고, 과거 선호도(선호하는 음식 카테고리 등)를 설정/관리할 수 있습니다.

**주요 흐름**
1. 첫 방문 시 기본 선호도 온보딩
2. 매 세션마다 오늘의 기분·예산 선택
3. 프로필 페이지에서 선호 카테고리 수정 가능

**데이터 포인트**
- 기분 (카테고리형, 다중 선택 가능)
- 예산 (단일 선택, 범위형)
- 선호 카테고리 (예: 한식/양식/일식/아시안/기타)
- 비선호 식재료 (옵션)

---

## 3. 팀 점심 계획 및 공유

**설명**
여러 명의 사용자가 각자의 기분과 예산을 입력하면, AI가 모두의 선호도를 고려하여 최적의 식당을 추천하고, 이를 팀원들과 공유할 수 있는 기능을 제공합니다.

**주요 흐름**
1. 호스트가 '팀 점심' 세션 생성 → 공유 링크 발급
2. 팀원들이 링크 접속 후 각자 기분·예산 입력
3. 모든 인원 입력 완료 시 AI가 공통 최적안 3개 추천
4. 투표 또는 호스트 확정으로 최종 선택

---

## 4. 식당 정보 및 리뷰

**설명**
추천된 식당 또는 주변 식당에 대한 상세 정보(주소, 전화번호, 운영 시간, 메뉴, 사진 등)와 사용자 리뷰를 제공하여 사용자가 최종 결정을 내리는 데 도움을 줍니다.

**표시 정보**
- 기본 정보: 식당명, 주소, 전화번호, 영업 시간
- 메뉴 및 가격대
- 대표 사진
- 리뷰 요약 (별점, 최근 리뷰)

---

## 5. 피드백 및 추천 개선

**설명**
사용자가 추천 결과에 대한 만족도와 피드백을 제공할 수 있도록 하여 AI 추천 모델을 지속적으로 고도화하고 개인화된 추천의 정확도를 향상시킵니다.

**주요 흐름**
1. 방문 후 간단한 만족도 평가 (좋아요/싫어요)
2. 선택적 상세 피드백 (맛, 가격, 분위기)
3. 수집된 데이터가 개인화 프로필에 반영
4. 다음 추천 시 가중치로 활용

---

## 6. 위치 기반 주변 식당 탐색

**설명**
사용자의 현재 위치를 기반으로 주변 식당 정보를 지도와 함께 제공하여, AI 추천 외에도 사용자가 직접 식당을 탐색할 수 있도록 돕습니다.

**주요 흐름**
1. 위치 권한 요청
2. 현재 위치 반경 500m 주변 식당 지도 표시
3. 필터 (카테고리, 가격대, 거리) 적용 가능
4. 식당 클릭 시 상세 정보(4번 기능) 연결

**제약 사항**: 위치 정보 활용 동의 필요
