# Claude Context — 26Q3_Todays-Lunch-Mate

## 프로젝트 목적
강남/판교 오피스 직장인의 점심 메뉴 결정 피로를 줄이는 AI 기반 점심 추천 웹 서비스.
사용자의 기분·예산·선호도를 입력받아 Claude Haiku가 3개의 맞춤 메뉴/식당을 추천한다.

## 핵심 컨텍스트
- 타겟: 20대 후반 ~ 40대 초반 직장인, 강남/판교 오피스 밀집 지역
- 핵심 페인포인트: 매일 '뭐 먹지?' 고민에 12분 낭비, 65% 같은 메뉴 반복
- AI 모델: Claude Haiku (빠른 응답, 비용 효율)
- 플랫폼: Web (모바일 웹 우선)
- 사용자 역할: User (단일 역할)

## 성공 지표 (핵심 KPI)
- AI 추천 수락률 60% 이상
- 주간 재사용률 3회 이상
- 점심 메뉴 결정 시간 5분 이내
- MAU 성장률 월 10% 이상

## 6대 핵심 기능 (기능명세서 기반)
1. AI 기반 맞춤형 식당 추천
2. 사용자 정보 입력 및 관리 (기분/예산/선호도)
3. 팀 점심 계획 및 공유
4. 식당 정보 및 리뷰
5. 피드백 및 추천 개선
6. 위치 기반 주변 식당 탐색

## 제약 사항
- Web 플랫폼 (네이티브 앱 아님)
- 식당 데이터 소스 확보 필요 (외부 API or 자체 구축)
- 개인정보 보호 및 위치 정보 활용 동의 필수
- 언어: 한국어 기본, 기술 용어 영어 병기
