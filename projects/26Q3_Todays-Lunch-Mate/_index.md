## 프로젝트 개요

직장인(강남/판교 오피스)의 점심 메뉴 결정 피로를 줄이기 위한 AI 기반 점심 추천 서비스.
사용자의 기분·예산·선호도를 고려하여 Claude Haiku가 3가지 맞춤 메뉴를 제안한다.

## 핵심 정보

| 항목 | 내용 |
|------|------|
| 서비스명 | 오늘의 점심 메이트 |
| 타겟 유저 | 점심 메뉴 고민이 많은 직장인 (강남/판교 오피스) |
| 핵심 문제 | 매일 '뭐 먹지?' 고민에 12분 낭비, 65% 같은 메뉴 반복 |
| AI 활용점 | 기분/예산 기반 맞춤 메뉴 3개 추천 (Claude Haiku) |
| 성공 기준 | 추천 수락률 60%, 주간 재사용 3회 이상 |
