# PPT 제작 가이드 — 컨설팅펌 수준 프리미엄 덱

> Status: Active
> Document Type: Design Guide

> Last Updated: 2026-06-26

Apple 디자인 그래머(단일 액센트·여백·near-invisible 크롬·tile 교차)를 **나눔고딕**으로 표현하여, 맥킨지/BCG 수준의 정돈된 강의 덱을 만들기 위한 규칙. `assets/pptx/generate.js`(pptxgenjs)가 이 가이드를 구현한다.

---

## 0. 3대 원칙

1. **한 장에 하나의 메시지.** 제목이 곧 결론. 본문은 근거.
2. **단일 액센트.** 모든 강조는 Action Blue `#0066CC` 하나로. 두 번째 브랜드색 없음.
3. **여백이 고급이다.** 채우지 말고 비운다. 요소 사이 최소 간격을 지키고, 가장자리 안전 여백을 침범하지 않는다.

---

## 1. 캔버스 & 그리드

- **규격**: 16:9 = 10 × 5.625 in (= 960 × 540 px @96dpi).
- **안전 여백(Safe area)**: 좌우 `0.7in`, 상단 `0.5in`, 하단 `0.45in`. 텍스트·핵심 요소는 이 안에만.
- **콘텐츠 폭**: `8.6in` (10 − 0.7×2).
- **세로 존(zone)**:

| 존 | Y 범위 (in) | 용도 |
|----|-------------|------|
| Kicker | 0.50–0.78 | 섹션 라벨/숫자 (옵션) |
| Title | 0.62–1.18 | 슬라이드 제목 (결론) |
| Subtitle | 1.18–1.55 | 한 줄 보조 설명 |
| Content | 1.65–4.75 | 본문·카드·표·이미지 |
| Footer rule | 5.02 | 1px hairline |
| Footer | 5.08–5.42 | 러닝 푸터(좌) + 페이지 번호(우) |

- **컬럼**: 12-컬럼 가정. 2분할 = `4.1in` 카드 × 2 (gutter 0.3). 3분할 = `2.73in` × 3. 5분할 = `1.55in` × 5 (gutter 0.3).
- **이미지/표는 콘텐츠 폭을 넘지 않는다.** 풀블리드는 표지·섹션 divider·데이터 히어로에서만.

## 2. 타이포그래피 — 나눔고딕 고정

> **모든 텍스트는 나눔고딕 패밀리만 사용한다.** 영문·숫자·코드도 동일. (제품명 등 불가피한 경우 제외)

| 패밀리 | 용도 |
|--------|------|
| `NanumGothic ExtraBold` | 제목·강조 헤드라인 |
| `NanumGothic Bold` | 소제목·카드 타이틀·강조 |
| `NanumGothic` | 본문·캡션·표·코드 |
| `NanumGothic Light` | 대형 숫자·airy 리드(절제 사용) |

### 타입 스케일 (pt)

| 토큰 | 크기 | 굵기 | 자간 | 용도 |
|------|------|------|------|------|
| Display | 40 | ExtraBold | -1 | 표지·데이터 히어로 |
| H1 (제목) | 26 | ExtraBold | -0.5 | 슬라이드 제목 |
| H2 | 19 | Bold | -0.3 | 카드/섹션 타이틀 |
| Lead | 16 | Regular | 0 | 부제·리드 |
| Body | 13.5 | Regular | 0 | 본문 |
| Caption | 11 | Regular | 0 | 보조·라벨 |
| Footnote | 9.5 | Regular | 0 | 푸터·출처 |
| Stat | 54–72 | ExtraBold | -1.5 | 핵심 수치 |

### 규칙
- 제목은 **2줄 이내**. line-height 1.15.
- 본문 line-height **1.45**. 한 단락 3줄 이내 권장.
- 자간: 큰 글자일수록 음수 자간(타이트)으로 고급감. 작은 글자는 0.
- **굵기 사다리: Light / Regular / Bold / ExtraBold** — 중간(가짜 Medium) 남발 금지.
- 텍스트 색은 본문 `ink`, 보조 `gray`, 강조만 `Action Blue`.

## 3. 컬러 시스템

| 토큰 | HEX | 용도 |
|------|-----|------|
| **Action Blue** | `#0066CC` | 유일 액센트 — 강조·CTA·키워드·rule |
| Focus Blue | `#0071E3` | 선택/포커스 강조 |
| Sky (on dark) | `#2997FF` | 다크 표면 위 강조 |
| Ink | `#1D1D1F` | 기본 텍스트·다크 타일 (순흑 대신) |
| Gray | `#86868B` | 보조 텍스트 |
| Gray-line | `#D2D2D7` | 구분선·테두리 |
| Hairline | `#E8E8ED` | 1px 미세 구분선 |
| Canvas | `#FFFFFF` | 기본 배경 |
| Parchment | `#F5F5F7` | 보조 배경·카드·교차 타일 |
| Tile (dark) | `#1D1D1F` | 다크 슬라이드·섹션 divider |
| Tint | `#EAF2FB` | 강조 카드 배경(블루 틴트) |

### 규칙
- **액센트는 면적의 10% 이하.** 포인트로만.
- 라이트↔다크(Parchment/Ink) **교차로 리듬**. 색 변화가 곧 섹션 구분.
- 그라디언트·네온·드롭섀도 금지. 그림자는 **제품 이미지/디바이스 목업에만** 단 하나(`0 18 50 rgba(0,0,0,.18)`).
- 표/카드 구분은 색 변화 또는 hairline으로. 굵은 테두리 금지.

## 4. 간격 리듬 (8pt 베이스)

`4 · 8 · 12 · 16 · 24 · 32 · 48 · 64` (px 기준, in 환산 ÷96).

- 제목—부제: 12–16px
- 부제—콘텐츠: 20–24px
- 카드 내부 패딩: **24px** (0.25in)
- 카드 사이 gutter: **20–24px**
- 요소 그룹 사이: 32–48px
- 텍스트와 이미지 사이: 최소 32px

---

## 5. 컴포넌트

| 컴포넌트 | 스펙 |
|----------|------|
| **카드** | 배경 Parchment, radius `8–12px`, 패딩 0.25in, 테두리 없음(또는 hairline). 강조 카드는 좌측 4px Action Blue 또는 Tint 배경 |
| **Pill 태그** | radius 9999, 패딩 6×12, 카테고리/상태 라벨 |
| **숫자 뱃지** | 26–32px 정사각, Ink 또는 Action Blue, 흰 숫자 |
| **프로세스/스텝** | 균등 분할 카드 + `→` 커넥터(Gray). 마지막 단계만 Action Blue |
| **표** | 헤더 Ink 배경/흰 글씨, 본문 흰 배경, 행 구분 hairline, 셀 패딩 충분히. 격자선 최소화 |
| **타이틀 rule** | 제목 아래 0.6in 길이 2px Action Blue 짧은 선(옵션, 통일 적용) |
| **디바이스 목업** | 둥근 프레임 + 단일 그림자. 스크린샷은 실제 캡처 |
| **콜아웃/인용** | 좌측 3px Action Blue + Parchment 배경, 본문보다 한 단계 큰 글씨 |

## 6. 슬라이드 아키타입

1. **Cover (표지)** — Ink 풀블리드. Display 제목 + 한 줄 토픽 + 메타(기관·날짜·시간·연사). 상단 짧은 Action Blue rule.
2. **Section divider** — Ink 풀블리드. `PART N` kicker + 큰 제목 + (옵션)미니 파이프라인.
3. **Statement** — 흰/Ink 배경, 큰 한 문장. 여백 최대.
4. **Comparison (2-up)** — AS-IS / TO-BE 또는 강의/실습. 좌우 카드, 우측을 Action Blue 강조.
5. **Process** — 3~5 스텝 가로 카드 + 커넥터.
6. **Data hero** — 큰 Stat + 한 줄 해석 + 출처 푸터.
7. **Matrix/Table** — 정돈된 표 1개. 한 슬라이드 1표.
8. **Showcase (이미지)** — 좌 텍스트 / 우 이미지(또는 반대). 캡션 필수.
9. **Closing** — Ink. 요약 4항목 + 연사·기관.

> 한 슬라이드에 아키타입 **하나**. 섞지 않는다.

## 8. 품질 체크리스트 (슬라이드마다)

- [ ] 안전 여백 침범 없음 (요소가 0.5in 경계 밖으로 안 나감)
- [ ] 제목 2줄 이내, 결론형
- [ ] 폰트 = 나눔고딕만, 스케일 토큰 준수
- [ ] 액센트 = Action Blue 하나, 면적 10% 이하
- [ ] 요소 정렬(좌측 라인 일치), 간격 리듬 일관
- [ ] 텍스트끼리/이미지와 겹침 없음
- [ ] 표/카드 패딩 충분, 글자 잘림 없음
- [ ] 라이트/다크 교차로 섹션 리듬
- [ ] 페이지 번호·러닝 푸터 존재(콘텐츠 슬라이드)
- [ ] 이미지 캡션·출처 표기

## 9. PDF 내보내기 — 원본 충실도

- **폰트 임베드 필수**: 나눔고딕 전 weight 설치 상태에서 PowerPoint로 내보내야 PDF에 임베드된다.
- 변환: macOS **PowerPoint AppleScript** `save … as save as PDF` (LibreOffice보다 충실).
- 검증: `pdftoppm`으로 페이지를 PNG 렌더 → 육안 검토(겹침·잘림·여백).
- 이미지는 2x(deviceScaleFactor 2)로 캡처해 또렷하게.
- 임베드 영상이 있는 슬라이드는 PDF에서 정지 포스터로 보이므로, **정적 이미지도 함께** 배치.

---

## 10. Do / Don't

**Do** — 결론형 제목 · 단일 액센트 · 넉넉한 여백 · 정렬 일치 · 한 장 한 메시지 · 라이트/다크 교차 · 실제 스크린샷.

**Don't** — 두 번째 액센트색 · 그라디언트/네온 · 굵은 테두리·과한 그림자 · 한 장에 여러 메시지 · 글자 꽉 채우기 · 중간 굵기 남발 · 폰트 혼용(나눔고딕 외).
