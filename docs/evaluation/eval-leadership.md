## 핵심 질문

> **"이 프로젝트에 투자할 가치가 있는가?"**

리더십/임원은 한정된 리소스를 배분하는 역할이다. PRD를 읽고 "이 프로젝트에 사람과 돈을 투입할 만한가"를 판단할 수 있어야 한다.

---

## 평가 체계

- **6개 항목**, 각 1-5점 (총 30점 만점)
- **통과 기준**: 총점 20점 이상 **+** 각 항목이 개별 최소 점수 이상
- **가중치**: 전략 정합성과 성공 측정 설계에 1.5배 가중

---

## 평가 항목

### 1. 전략 정합성 (Strategic Alignment) — 가중치 x1.5

**평가 질문**: 이 프로젝트가 회사/조직의 OKR (Objectives and Key Results, 목표 및 핵심 결과) 또는 사업 방향과 직접 연결되는가?

| 점수 | 기준 |
|------|------|
| **1점** | OKR이나 사업 방향 언급이 전혀 없다. 왜 이 프로젝트를 하는지 조직 맥락에서 이해할 수 없다 |
| **2점** | OKR을 언급하지만, 연결이 모호하거나 간접적이다 |
| **3점** (최소 통과) | 특정 OKR과 명시적으로 연결되며, 이 프로젝트가 해당 OKR에 기여하는 경로가 설명된다 |
| **4점** | 3점 조건 + 다른 진행 중인 이니셔티브와의 관계(시너지/충돌)까지 고려한다 |
| **5점** | 4점 조건 + 중장기(2-3분기) 로드맵에서의 위치와 이후 확장 방향까지 제시한다 |

---

### 2. 문제 정의 명확성 (Problem Clarity) — 가중치 x1.0

**평가 질문**: 해결하려는 문제가 데이터와 근거로 뒷받침되며, 누가 읽어도 같은 문제를 이해하는가?

| 점수 | 기준 |
|------|------|
| **1점** | 문제가 정의되어 있지 않거나, "사용자가 불편해한다" 수준의 추상적 서술만 있다 |
| **2점** | 문제를 서술하지만 정량 데이터가 없다. 감(Gut Feeling)에 의존한다 |
| **3점** (최소 통과) | 정량 데이터(사용자 수, 비율, 매출 영향 등)로 문제의 크기와 영향을 뒷받침한다 |
| **4점** | 3점 조건 + 사용자 리서치(인터뷰, 설문, VOC)의 정성 데이터까지 포함한다 |
| **5점** | 4점 조건 + 문제의 근본 원인(Root Cause)을 분석하고, 선행 지표로 문제 추이를 추적할 수 있다 |

---

### 3. 투자 대비 수익 합리성 (ROI Justification) — 가중치 x1.0

**평가 질문**: 이 프로젝트에 투입되는 비용 대비 기대 효과가 합리적으로 추정되어 있는가?

| 점수 | 기준 |
|------|------|
| **1점** | 비용이나 기대 효과에 대한 언급이 전혀 없다 |
| **2점** | "효과가 클 것으로 기대한다" 수준의 정성적 서술만 있다 |
| **3점** (최소 통과) | 투입 비용(인력·인프라)과 기대 효과(매출·비용절감)가 개략적 수치로 추정되어 있다 |
| **4점** | 3점 조건 + ROI (Return on Investment, 투자 대비 수익률) 또는 Payback Period (투자 회수 기간)가 계산되어 있다 |
| **5점** | 4점 조건 + 낙관/비관 시나리오별 ROI가 제시되고, 리스크 요인이 명시되어 있다 |

---

### 4. 시장·고객 적합성 (Market & Customer Fit) — 가중치 x1.0

**평가 질문**: 대상 고객이 명확하고, 시장 맥락(경쟁사, 트렌드)이 반영되어 있는가?

| 점수 | 기준 |
|------|------|
| **1점** | 대상 고객이 정의되어 있지 않다. "모든 사용자" 수준의 서술이다 |
| **2점** (최소 통과) | 대상 고객 세그먼트가 정의되어 있으나, 행동 패턴이나 니즈가 구체적이지 않다 |
| **3점** | 2점 조건 + 고객의 행동 패턴, Pain Point, Jobs-to-be-Done이 구체적으로 서술된다 |
| **4점** | 3점 조건 + 경쟁사 또는 시장 벤치마크가 포함되어 상대적 위치를 알 수 있다 |
| **5점** | 4점 조건 + TAM/SAM/SOM (Total/Serviceable/Obtainable Market, 전체/접근가능/획득가능 시장) 또는 시장 기회 규모가 추정되어 있다 |

---

### 5. 우선순위 정당성 (Priority Justification) — 가중치 x1.0

**평가 질문**: "왜 지금, 다른 것보다 이것을 먼저 해야 하는가"에 대한 답이 있는가?

| 점수 | 기준 |
|------|------|
| **1점** | 우선순위에 대한 언급이 없다. 왜 이것이 지금 중요한지 알 수 없다 |
| **2점** | "중요하다"고 서술하지만, 다른 후보 대비 비교 근거가 없다 |
| **3점** (최소 통과) | "왜 지금"에 대한 타이밍 근거(시장 변화, 경쟁 대응, 내부 여건)가 제시된다 |
| **4점** | 3점 조건 + 하지 않았을 때의 기회비용(Opportunity Cost)이 서술된다 |
| **5점** | 4점 조건 + ICE (Impact, Confidence, Ease) 또는 RICE (Reach, Impact, Confidence, Effort) 등 프레임워크 기반으로 우선순위가 정량화되어 있다 |

---

### 6. 성공 측정 설계 (Success Measurability) — 가중치 x1.5

**평가 질문**: 프로젝트의 성공/실패를 어떤 지표로, 어떻게 판단하는지 구체적으로 설계되어 있는가?

| 점수 | 기준 |
|------|------|
| **1점** | 성공 지표가 정의되어 있지 않다 |
| **2점** | "사용자 만족도 향상" 같은 측정 불가능한 지표만 있다 |
| **3점** | 구체적 지표(CTR, 전환율 등)가 정의되어 있으나, 현재값·목표값이 없다 |
| **4점** (최소 통과) | 지표에 현재값(Baseline)과 목표값(Target)이 있고, 측정 방법이 명시되어 있다 |
| **5점** | 4점 조건 + NSM/핵심/보조 지표 계층이 설계되고, 릴리즈 게이트(Go/No-Go 기준)가 정의되어 있다 |

````
당신은 IT 서비스 회사의 시니어 리더십(C-Level 또는 VP급)입니다.
아래 PRD를 읽고, **리더십/임원 관점**에서 6개 항목을 평가해주세요.

## 평가 항목 (각 1-5점)

1. **전략 정합성** (가중치 x1.5, 최소 ≥3)
   - 회사/조직의 OKR·사업 방향과 직접 연결되는가?
   - 5점: 중장기 로드맵 위치 + 이니셔티브 간 관계까지 설명

2. **문제 정의 명확성** (가중치 x1.0, 최소 ≥3)
   - 정량 데이터로 문제 크기와 영향을 뒷받침하는가?
   - 5점: 근본 원인 분석 + 선행 지표 추적 가능

3. **투자 대비 수익 합리성** (가중치 x1.0, 최소 ≥3)
   - 투입 비용과 기대 효과가 수치로 추정되어 있는가?
   - 5점: 낙관/비관 시나리오별 ROI + 리스크 요인 명시

4. **시장·고객 적합성** (가중치 x1.0, 최소 ≥2)
   - 대상 고객과 시장 맥락이 구체적으로 반영되어 있는가?
   - 5점: TAM/SAM/SOM 또는 시장 기회 규모 추정 포함

5. **우선순위 정당성** (가중치 x1.0, 최소 ≥3)
   - "왜 지금, 다른 것보다 이것을 먼저"에 대한 답이 있는가?
   - 5점: 정량화된 우선순위 프레임워크(ICE/RICE 등) 사용

6. **성공 측정 설계** (가중치 x1.5, 최소 ≥4)
   - Baseline과 Target이 있는 구체적 지표가 설계되어 있는가?
   - 5점: NSM/핵심/보조 계층 + 릴리즈 게이트(Go/No-Go) 정의

## 출력 형식

각 항목에 대해:
- **점수**: N/5
- **근거**: 점수를 준 구체적 이유 (PRD의 어떤 부분이 좋은지/부족한지)
- **개선 제안**: (3점 미만일 때) 어떻게 보완하면 점수가 올라가는지

마지막에 **총평**과 **Pass/Fail** 판정을 내려주세요.
(통과 기준: 가중 합계 23/35 이상 + 개별 최소 점수 충족)
````
